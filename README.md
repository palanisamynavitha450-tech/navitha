# Navitha Portfolio

Modern React + Tailwind CSS portfolio website featuring:

- Dark/light mode toggle with smooth animation
- Glassmorphism, soft shadows, and premium motion effects
- Five page routes: Home, About, Skills, Projects, Contact
- Animated hero, typing effect, project filters, and mini Tic Tac Toe game
- Contact form with validation and toast notifications

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```
2. Run development server:
   ```bash
   npm run dev
   ```
3. Build production output:
   ```bash
   npm run build
   ```

## Notes

- The project is built with Vite, React, Tailwind CSS, Framer Motion, React Router, canvas-confetti, and React Toastify.
- A placeholder resume document is included in `public/resume.pdf`.
